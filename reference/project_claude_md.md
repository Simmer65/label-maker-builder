## Architecture

- `layout_label()` is the single layout engine: it computes text runs in
  **inches**, backend-agnostic via a "measurer" (point size → width/
  line-height in inches). `TkMeasurer` backs the preview canvas,
  `GdiMeasurer` backs the printer DC — this is what keeps preview and print
  WYSIWYG-consistent; both cache metrics per (family, size, bold) since the
  font family is per-label style. Change layout behavior only there, never in
  the preview or print code separately.
- Printing (`print_sheet`) is raw GDI via pywin32: builds a DEVMODE forcing
  portrait sheet media (the driver's matching paper code if one exists, else
  a custom size in 0.1 mm units = inches × 254), then draws at device DPI,
  subtracting the printer's physical unprintable offset and adding the stored
  calibration offset. The driver dialog is never opened. The alignment test
  (`print_alignment_sheet`) is a separate path that forces **letter** media
  via `_create_printer_dc(letter=True)`; the Calibration dialog computes
  offsets from ruler measurements via `compute_calibration()`.
- Sheet geometry is **config-driven**: defaults live in `default_config()`
  under `"geometry"`, and `_apply_geometry()` assigns the module-level
  geometry constants (and derived values like `ROW_PITCH` and the alignment
  targets) at startup, before any UI is built. To support a different label
  sheet, change the config — not scattered constants.
- The entry rows are locked to the preview's vertical geometry (`ROW_PITCH`
  = one label pitch at preview scale, a top spacer matching the sheet's
  first-label offset, fixed row height via `pack_propagate(False)` after
  measuring natural width) so row N sits level with label N in the preview.
  Preserve that coupling when touching either side.
- Keyboard model: Enter/Tab = next label, Shift+Enter = newline, **Ctrl+Tab =
  literal tab character** (required for the tab-L/R split mode),
  Ctrl+1/2/3 = assign format, Ctrl+P / Ctrl+Shift+P = print / quick print,
  Ctrl+N = new sheet.

## Functional notes

- Font: per-label font family via a dropdown in the style editor (default
  {{FONT_NAME}}, falls back to Courier New). A label holds at most
  {{MAX_LINES}} lines; each line has its own size (explicit or auto-fit) and
  bold setting.
- Three global format presets (style only — including font — never text):
  labels stay linked to their preset — editing a format restyles every linked
  label; a manual Style… tweak detaches the label. The Style… dialog has a
  Format row that loads a preset into the controls (untouched OK keeps the
  link; tweaking detaches). A default format and "apply to all" action exist
  in the Formats menu.
- Each entry row has a ⋮ drag handle to reorder labels: the drop moves the
  label's data (text, style, preset link) and shifts the labels in between;
  the row widgets never move, keeping the row-to-preview alignment.
- Quick Print goes straight to the stored printer, applying the DEVMODE paper
  setup programmatically on every job — never rely on driver defaults or
  open the driver dialog. Quick Print and the alignment test confirm with
  auto-hiding toasts (`show_toast`).
- Blank rows print nothing (partial-sheet reuse); "Start at position N"
  shifts labels down. The sheet auto-saves on exit; named label sets can be
  saved/loaded.
